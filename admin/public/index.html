    프로젝트 태그 복수 선택

    책 정보

    책 안에 실제로 쓰인 언어를 적어주세요. 한국어로만 쓴 책은 국문 칸에 ‘한국어’, 영문 칸에 ‘Korean’을 적으면 각 언어 화면에서 쪽수 옆에 표시됩니다. 글이 없는 책은 비워 두세요.

    표지

    앞표지를 비워두면 첫 카드 앞면을 사용합니다.

    내지

    첫 낱장이 놓일 위치를 선택하세요. PDF에서 이미 두 쪽이 한 펼침면으로 묶인 부분은 원래 좌우 배치를 유지합니다.

    장별 재단 크기

    종이 한 장은 앞뒤 두 쪽입니다. 1장부터 순서대로 계산하며, 같은 장에 여러 구간이 겹치면 아래 구간의 입력값을 적용합니다.

    카드 순서와 앞뒷면

    각 PDF 페이지를 한 면으로 사용합니다. 뒷면 이미지를 비운 카드는 빈 뒷면으로 표시됩니다.

    기본 표시는 등록된 썸네일을 유지합니다. 썸네일이 없으면 카드 묶음을 보여줍니다.

      프로젝트에서 보여줄 이미지를 순서대로 추가해주세요.
